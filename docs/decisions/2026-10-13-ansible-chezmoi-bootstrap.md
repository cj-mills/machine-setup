# Ansible for the system layer, chezmoi for the user layer, a thin bootstrap

Ansible (system) + chezmoi (user) + thin bootstrap; Nix/Home Manager rejected as primary because tutorials and devices target stock Ubuntu/JetPack/Pi OS and Windows is in scope. NixOS explored on the test partition.
